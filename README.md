# Blood Bank Management System

A console-based Blood Bank Management System developed using C programming language.

## Features
- Add blood group
- Delete blood group
- Search blood group
- Display available blood stock
- Update blood quantity
- Create blood group package

## Technologies Used
- C Programming
- Structure
- Array
- Function
- String Handling

## Blood Groups Supported
- A+
- A-
- B+
- B-
- O+
- O-
- AB+
- AB-

## Future Improvements
- File handling for saving data
- Admin login system
- Donor and receiver management
- Blood request system
- Expiry date tracking
- Better user interface
